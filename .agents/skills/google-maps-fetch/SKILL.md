# Google Maps 店家與景點資訊讀取技能 (Google Maps Fetch Skill)

本技能提供專案在處理「**資訊分享（景點推薦、美食探訪）**」時，自動自 Google Maps 檢索、比對與結構化萃取店家實體情報的能力，避免人工重複查閱地址與營業時間。

---

## 1. 觸發時機 (Trigger Conditions)

符合以下任一條件時自動裝載本技能：
1. 使用者在新增心得對話框選擇「**資訊分享**」主題，且輸入內容包含特定店名、景點或 Google Maps 網址。
2. 使用者明確要求「查一下這家店的營業時間」、「幫我看看這間店離哪個捷運站比較近」或「補充 Google Maps 店家資訊」。

---

## 2. 資訊萃取欄位規格 (Extraction Schema)

檢索後應整理為標準的結構化資料：

| 欄位名稱 | 說明 | 範例 |
| :--- | :--- | :--- |
| **店家/景點名稱** | Google Maps 官方註冊之精確名稱 | `象山六號麵館` |
| **鄰近大眾運輸/地標** | 距最近捷運站、火車站出口與步行時間 | `捷運象山站 2 號出口步行約 6 分鐘` |
| **營業時間與公休日** | 平假日營業時段、中場休息與固定公休日 | `11:30–14:00, 17:00–20:30 (每週一公休)` |
| **客觀評價與人潮狀況** | 評分與熱門排隊時段摘要 | `Google 評分 4.2 星；中午 12:10–13:00 為尖峰排隊時段` |
| **避坑/貼心提醒** | 停車便利性、低消、冷氣強弱或付款方式 | `僅收現金；店內座位較少，建議避開正中午` |

---

## 3. 處理流程與解析邏輯 (Step-by-Step Procedure)

### 步驟一：輸入驗證與關鍵字萃取
- 分析使用者輸入：
  - 若為 **Google Maps 網址**（`goo.gl/maps/...` 或 `maps.app.goo.gl/...`），提取其對應 Place ID 或地點名稱。
  - 若為 **純文字名稱**（如「永康牛肉麵」、「大安森林公園落羽松」），結合使用者所在的城市定位（預設台灣/台北）進行精準匹配。

### 步驟二：地點資訊檢索
- 優先讀取地點之官方 Google Maps 頁面或 Google Places 資訊。
- 嚴格查核營業時間，特別留意是否有「暫停營業」或「已歇業」之標記。

### 步驟三：合規轉譯與風格套用
萃取後的資料不可直接生硬貼出，必須嚴格依照 [.agents/rules/docs-writing.md](../../rules/docs-writing.md) 的「資訊分享（景點推薦）」規範轉化：
- **親切隨興、風趣務實**：多用語助詞（「啦」、「喔」）與生動標點符號。
- **實用 emoji 標註**：
  - 交通：🚇、🚶‍♂️
  - 美食/景點：🍜、☕、🌳
  - 避坑/時間：⚠️、⏰
- **客觀有優點有缺點**：好吃的照實誇，缺點（如難停車、冷氣不涼、排隊曬）直白提醒，維持真實無業配的素人視角。

---

## 4. 容錯與退場機制 (Fallback Strategy)

1. **查無精確店家**：
   - 若使用者輸入之店名有同名歧義（例如全台有多家分店），主動提示：「查到台北與台中各有一間，幫您預設採用台北本店的交通資訊囉」。
2. **無官方營業時間登記**：
   - 不隨意瞎編。標註「⚠️ 該店家 Google Maps 尚未登記固定營業時間，建議出發前致電確認」。
3. **無網路或無 API Key 情境**：
   - 採用內建之標準生活常識範本進行語意模擬，並在說明中保留提醒，絕不拋出系統崩潰報錯。
