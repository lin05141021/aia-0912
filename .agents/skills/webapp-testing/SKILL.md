# Web 應用測試與驗收檢驗規範 Skill (WebApp Testing)

本 Skill 定義輕量前端應用在本地開發與線上部署階段的驗證程序、測試矩陣與環境驗收清單，確保功能零缺陷交付。

---

## 核心測試維度

```text
[ 功能測試 Functional ] ➔ [ 響應式佈局 RWD ] ➔ [ 異常與邊界 Edge Cases ] ➔ [ 部署與快取 Deployment ]
```

---

## 1. 互動功能測試檢驗點

- **新增流程檢驗**：
  - 開啟彈窗時焦點是否自動移至輸入框。
  - 主題單選切換（三大主題）時高亮樣式是否正常。
  - 本地照片上傳（FileReader）與預設推薦配圖切換是否正常。
  - 送出後是否成功插入列表首位，表單是否自動清空重設。
- **社群回饋檢驗**：
  - 點擊按讚圖示：讚數即時 `+1 / -1`，愛心顏色與彈跳動畫正常觸發。
  - 雙擊照片：中央浮動大愛心動畫是否正常爆發，並聯動按讚。
  - 收藏書籤：狀態切換與 Toast 提示是否正常運作。
  - 留言發布：送出後即時插入留言列表，計數器是否自動累加。
- **本地持久化檢驗**：
  - 瀏覽器按下 F5 重新整理後，所有新增的卡片、點讚狀態與留言是否完整保留。

---

## 2. 跨裝置與響應式 (RWD) 測試矩陣

- **桌機環境 (寬螢幕 >= 1024px)**：
  - 內容主卡片是否維持在 `580px` 舒適閱讀寬度，居中對齊無歪斜。
- **平板與中型螢幕 (768px ~ 1023px)**：
  - 兩欄式表單與網格按鈕是否正常排列。
- **行動手機螢幕 (360px ~ 480px)**：
  - 頁面水平方向是否有未受控的捲軸（`overflow-x` 破版）。
  - 觸控熱區（按鈕、圖示、選單）是否容易用拇指點擊（最小尺寸 `>= 44px`）。

---

## 3. 靜態部署與快取穿透防禦驗收

在 GitHub Pages 等靜態託管環境，務必執行以下驗收程序：
1. **快取驗證指令**：
   ```bash
   curl.exe -s -I "https://[username].github.io/[repo]/style.css?v=[version]"
   ```
   - 確保 HTTP 狀態碼為 `200 OK`，且 `Content-Length` 符合最新檔案大小。
2. **.nojekyll 存在性檢核**：
   - 確保專案根目錄包含 `.nojekyll`，避免 Jekyll 處理器阻礙更新。
3. **無痕視窗驗證**：
   - 使用無痕模式或 <kbd>Ctrl</kbd> + <kbd>F5</kbd> 開啟線上網址，確認樣式不掉落。

---

## 驗收通過清單 (Acceptance Sign-off)

- [ ] 本地功能測試無任何未捕捉的 JavaScript 錯誤（Console 乾淨）。
- [ ] 模擬手機窄螢幕無破版或橫向捲軸。
- [ ] 惡意輸入特殊字元（如 `<script>alert(1)</script>`）時均被轉義，無 XSS 疑慮。
- [ ] 線上部署網址載入順暢，所有外部樣式與腳本均能正確載入。
