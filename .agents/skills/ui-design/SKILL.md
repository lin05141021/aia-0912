# 使用者介面與視覺設計規範 Skill (UI Design)

本 Skill 定義產品的視覺美學、排版網格、色彩 Token、微互動動效規範，並落實以「微軟正黑體」為基準的繁體中文排版美學。

---

## 視覺與排版核心準則

1. **字型基準**：
   - 網頁 CSS 全域優先採用**微軟正黑體**，中英數混排時保持一個半形空格：
     ```css
     body {
       font-family: "Microsoft JhengHei", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
     }
     ```
   - 內文行高設定為 `1.6 ~ 1.75`，確保長篇閱覽舒適度；標題適度微縮字距（`-0.01em ~ -0.02em`）。
2. **間距與 8px 網格系統**：
   - 所有元素間距、外距（margin）、內距（padding）皆遵循 `4px / 8px / 12px / 16px / 24px / 32px` 的級距倍數。
3. **色彩設計系統 (Design Tokens)**：
   - **背景與表面**：底層使用暖灰色調（如 `#f6f7f9`），卡片表面採用純白（`#ffffff`），搭配極細邊框（`#e5e7eb`）形成乾淨邊界。
   - **主色與品牌色**：克制使用高明度藍/墨色（如 `#2563eb`），避免大面積螢光色。
   - **情態反饋色**：愛心紅色（`#ef4444`）、收藏金黃（`#f59e0b`）、成功綠色（`#10b981`）。

## 微互動與多巴胺回饋動效

為達成「降低輸入阻力、激勵記錄習慣」的目標，介面需具備直觀且不刺眼的微互動反饋：

- **愛心彈跳 (Heartbeat Pulse)**：點擊時以彈簧貝茲曲線（`cubic-bezier(0.175, 0.885, 0.32, 1.275)`）進行短暫縮放。
- **雙擊圖片愛心爆發 (Double-Tap Pop)**：中央浮現大愛心並淡出，提供仿 Instagram 的經典回饋感。
- **即時 Toast 通知**：置於畫面底部中央，伴隨淡入向上位移與自動淡出。
- **毛玻璃效果 (Frosted Glass)**：頂部導航列與標籤覆蓋層搭配 `backdrop-filter: blur(12px)`，提升精緻度。

---

## 響應式佈局 (RWD) 規範

- **行動優先（Mobile First）思維**：
  - 核心卡片預設最大寬度鎖定在 `580px ~ 640px` 之間（最適合閱覽的社群寬度）。
  - 螢幕寬度 `<= 600px` 時：
    - 外容器邊界縮減至 `0.5rem ~ 1rem`。
    - 彈窗內的選項欄由橫向多欄轉換為垂直單欄，確保按鈕點擊熱區（Touch Target）至少達到 `44px x 44px`。
    - 隱藏非關鍵裝飾文字，維持畫面清爽。

---

## 驗收檢核標準

- [ ] 字型正確套用微軟正黑體，無破字或字體缺字 fallback 不良。
- [ ] 中文段落與英數混排之間均有適當空格。
- [ ] 互動元素皆具備明確的 hover / active / focus 視覺反饋。
- [ ] 在行動裝置（iPhone/Android）窄螢幕上無任何非預期的水平捲軸破版。
