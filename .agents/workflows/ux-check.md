# UX 流程檢核規範：日記卡片新增流程 (UX Check Workflow)

本文件定義使用者進入網頁後，瀏覽歷史紀錄與透過互動引導新增日記卡片的標準使用者體驗（UX）流程與檢核規格。

---

## 流程目標

提供直覺、不囉嗦的操作體驗，引導使用者將隨手的簡短想法，依據專案規範風格擴展為結構完整、排版合宜的心得卡片，並歸檔展示。

---

## 標準操作流程 (Step-by-Step UX Flow)

### 步驟一：首頁歷史日記卡片展示
- **使用者情境**：使用者載入網頁。
- **介面反饋**：
  - 首頁即刻呈現過往建立的日記卡片列表。
  - 卡片依時間倒序排列（最新發布排在最前）。
  - 若尚無任何卡片，呈現簡約低調的空狀態提示（Empty State），引導使用者建立第一篇日記。
- **檢核重點**：
  - 頁面載入速度流暢，無閃爍或非預期的破版。
  - 卡片文字預設套用「微軟正黑體」，中英數字混排留有適度空隙。

### 步驟二：觸發新增與選擇主題
- **使用者情境**：使用者點擊「新增」按鈕。
- **介面反饋**：
  - 開啟輕量互動對話框（Modal / Drawer），不阻斷整體操作節奏。
  - 清楚提示主題分類選項，提供三個明確選項：
    1. **專業知識分享**（閱讀心得、文章金句、專業文章連結）
    2. **心得雜記**（生活體悟、學習反思）
    3. **資訊分享**（景點推薦、行程、美食與私房清單）
- **檢核重點**：
  - 選項按鈕點擊區域舒適，具備清楚的聚焦與選中狀態反饋。

### 步驟三：輸入簡短內容
- **使用者情境**：使用者選定主題後，進入內容輸入步驟。
- **介面反饋**：
  - 提供多行輸入框（Textarea），並附上簡潔的 Placeholder 引導文字（例如：「簡短寫下核心觀點、體悟或景點特色...」）。
  - 避免要求填寫過多冗長的非必要欄位。
- **檢核重點**：
  - 輸入框支援自動換行與基本的文字長度防護，不可因大量文字貼上而破壞介面。

### 步驟四：依循 Rules 各主題風格生成小短文
- **使用者情境**：使用者送出簡短內容，系統依主題與規範轉換內容。
- **文風檢核**（嚴格比對 [.agents/rules/docs-writing.md](../rules/docs-writing.md)）：
  - **通用底層**：沉穩低調、客觀務實、嚴禁浮誇煽情詞、字型預設微軟正黑體、中英數留空格。
  - **心得雜記**：保有克制幽默，適度加入生活或除錯的自嘲元素，引發誠懇共鳴。
  - **專業知識分享**：檢核資訊與出處正確性，採「我用過了很順手 / 聽說這個很厲害跟大家分享」的實踐者同儕視角，拒絕說教式專家口吻。
  - **資訊分享**：語氣輕鬆隨興、風趣隨意，適量加入語助詞與 emoji；絕非網美業配風，誠實點出優點與缺點/注意事項。
- **檢核重點**：
  - 生成後提供即時預覽，並允許使用者手動潤飾或確認。

### 步驟五：照片確認與生圖處理
- **使用者情境**：確認文字後，處理卡片配圖。
- **介面反饋**：
  - 詢問使用者：「是否要自行上傳照片，或是依據主題風格為您生成/配圖？」
  - 提供兩種路徑：
    1. **手動上傳**：支援常見圖檔格式（JPG, PNG, WebP），並提供即時縮圖預覽。
    2. **風格生圖 / 推薦**：依據主題風格自動產生或配對：
       - **心得雜記**：生活紀實感、安靜舒適日常、自然光、低飽和暖灰調。
       - **專業知識分享**：現代工作空間、整潔桌面、筆電/螢幕微光、冷灰科技感。
       - **資訊分享**：旅途隨拍視角、真實自然光、無過度濾鏡與擺拍感。
- **檢核重點**：
  - 圖片具備完整的 `alt` 替代文字描述。
  - 圖片載入失敗時有優雅的 Fallback 佔位處理，不影響文字閱讀。

### 步驟六：製成卡片與持久化
- **使用者情境**：使用者完成最終確認。
- **介面反饋**：
  - 卡片立即組合完成並插入首頁列表首位。
  - 彈窗優雅關閉，給出短暫且不突兀的成功提示（Toast）。
  - 狀態同步寫入本地存儲（`localStorage`），確保重新整理網頁後資料依然存在。
- **檢核重點**：
  - 新增後首頁滾動位置平順，新卡片與舊卡片樣式維持嚴格一致。

---

## 驗收清單 (Checklist)

- [ ] 進入網頁時，過往日記卡片能正確自 `localStorage` 讀取並渲染。
- [ ] 點擊「新增」時，主題三選一（專業知識分享、心得雜記、資訊分享）互動明確。
- [ ] 簡短文字輸入體驗順暢，能依規範生成符合「沉穩低調務實」風格之小短文。
- [ ] 提供「自行上傳照片」與「風格配圖」兩種彈性選擇。
- [ ] 最終卡片字型皆為微軟正黑體，無破版、無浮誇文詞，完美融入首頁瀑布流。
