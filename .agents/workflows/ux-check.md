# UX 流程檢核規範：日記卡片新增流程 (UX Check Workflow)

本文件定義使用者進入網頁後，瀏覽歷史紀錄與透過引導流程新增日記卡片的標準使用者體驗（UX）流程與檢核規格。

---

## 流程核心理念

專為「養成紀錄習慣」設計，提供極低操作心智負擔的「簡要輸入」引導模式：
使用者僅需隨手填寫一句話或簡短摘要（例如貼上 Google Maps 連結與推薦原因），系統即依循規範自動擴寫為沉穩質感的短文，並在彈窗中讓使用者檢核確認、挑選配圖與推薦標籤，最後才發佈至 IG 動態牆。

---

## 標準操作流程 (Step-by-Step UX Flow)

### 步驟一：首頁歷史日記卡片展示
- **使用者情境**：使用者載入網頁。
- **介面反饋**：
  - 首頁即刻呈現過往建立的個人生活日記卡片列表。
  - 卡片依發佈時間倒序排列（最新發布排在最前）。
  - 若尚無任何卡片，呈現簡約低調的空狀態提示（Empty State），並提供「記錄第一篇心得」按鈕。
- **檢核重點**：
  - 頁面載入速度流暢，無閃爍破版。
  - 文字一律採用微軟正黑體，中英數混排留有適度空隙。

### 步驟二：觸發新增與選擇主題
- **使用者情境**：使用者點擊頂部導航之「快速記錄」或「新增」按鈕。
- **介面反饋**：
  - 彈出式互動對話框（Modal），背景具備 4px 模糊微光遮罩。
  - 提供三種清晰的主題選項（莫蘭迪色彩對應）：
    1. **專業知識分享**（融冰淡水藍 #c8dce8）：閱讀筆記、技術架構、實踐者同儕分享。
    2. **心得雜記**（淡蘭紫霧 #d7d0db）：生活日常體悟、微幽默與自嘲除錯隨筆。
    3. **資訊分享**（蜜桃粉杏 #e8c9bc）：景點推薦、在地美食實訪、避坑情報。
- **檢核重點**：
  - 點擊主題時具備清楚的高亮與外框選中回饋。

### 步驟三：簡要輸入 (Brief Note Input)
- **使用者情境**：使用者在簡要輸入欄填寫重點或貼上連結，例如：
  > `以父親節為由 終於嘗試 非常推薦 https://maps.app.goo.gl/S8AajshsCyrtvqzY9`
- **介面反饋**：
  - 提供單行或多行簡要輸入框（Placeholder 提供範例引導）。
  - 提供一鍵填入範例按鈕，方便快速體驗。
  - 提供顯眼的「✨ 依 Rules 寫作風格生成小短文」主要觸發按鈕。
- **檢核重點**：
  - 降低使用者輸入門檻，不需要使用者一開始就構思長篇大論。

### 步驟四：依 Rules 生成小短文，呈現在彈窗中確認修改
- **使用者情境**：點擊生成按鈕，系統即時轉換為完整短文。
- **文風與技能轉譯邏輯**（嚴格比對 [.agents/rules/docs-writing.md](../rules/docs-writing.md)）：
  - **通用底層**：沉穩低調、客觀務實、嚴禁浮誇煽情詞、字型預設微軟正黑體、全形標點。
  - **資訊分享（連動 google-maps-fetch 技能）**：
    - 若輸入包含 Google Maps 網址或具體店家（如 Fa Burger 敦化店、牛肉麵、咖啡館），調用 [.agents/skills/google-maps-fetch/SKILL.md](../skills/google-maps-fetch/SKILL.md)。
    - 自動提取或補充地點周邊交通（如捷運站與步行時間）、營業時間與客觀探訪建議（避坑提醒）。
    - 語氣風趣隨意、客觀不業配、適度加入生活化 emoji。
  - **心得雜記**：微量克制幽默，加入生活或程式碼除錯的自嘲元素。
  - **專業知識分享**：以「我用過了很順手 / 聽說這個很厲害」的實踐者分享角度出發，杜絕說教式口吻。
- **介面反饋與確認修改**：
  - **生成的完整短文即時填入編輯文字框（Textarea）**。
  - **使用者可在彈窗中直接檢核、潤飾或確認文字**，並可點擊「🪄 一鍵依沉穩規範自動潤飾排版」微調標點。
- **檢核重點**：
  - 產出的短文絕不直接無確認發布，必須先留在彈窗供使用者過目與自由編修。

### 步驟五：照片決策（自行上傳 或 AI 依內容智慧生成）
- **使用者情境**：確認短文後，決定卡片配圖方式。
- **介面反饋**：
  - 提供分頁按鈕：「✨ AI 依內文智慧生圖」與「📸 自行上傳照片」。
  - **AI 動態生圖**：根據步驟四生成或修改後的文章內容，自動語意分析並提取關鍵字，即時動態生成 1:1 IG 正方形配圖（漢堡美食、工作桌、咖啡、山林步道等），嚴禁固定死板四張圖限制。
  - **自行上傳照片**：支援本地照片拖曳或點選上傳，自動適配 1:1 比例與即時預覽。
- **檢核重點**：
  - 圖片預覽具備 1:1 正方形比例與質感外框。

### 步驟六：點選推薦 Hashtag (Select Recommended Hashtags)
- **使用者情境**：挑選貼文標籤。
- **介面反饋**：
  - 系統根據主題與文章內容（如店家名稱、節慶、交通、氛圍），自動計算並呈現一組**推薦 Hashtag 標籤晶片 (Chips)**。
  - 例如：`#FaBurger敦化店` `#父親節聚餐` `#台北美食` `#捷運美食` `#避坑提醒` `#資訊分享`。
  - 使用者點擊標籤晶片即可快速選取（高亮反饋）或取消，選中的標籤自動同步至貼文標籤列，亦可自行手動追加。
- **檢核重點**：
  - 標籤晶片點擊流暢，符合注音輸入「選推薦 hashtag」之直覺易用性。

### 步驟七：最後才發佈與持久化
- **使用者情境**：確認內容、圖片、地點與標籤皆無誤後，點擊「發佈 IG 筆記卡片」。
- **介面反饋**：
  - 彈窗優雅關閉，給出「🎉 已歸檔至個人 IG 筆記牆！」的輕量 Toast 提示。
  - 卡片立即依照 **Instagram (IG) 經典 8 大發文格式** 完整組合，插入首頁列表首位：
    1. 圓形頭像、作者帳號、地點與 PANTONE 主題標籤
    2. 1:1 正方形照片、雙擊大愛心回饋
    3. 愛心按讚、留言、紙飛機分享、書籤收藏工具列
    4. 讚數統計、帳號與短文展開、Hashtag 標籤
    5. 精選留言列表與灰階發佈時間
    6. 底部表情快捷與快速留言輸入
  - 資料同步寫入 `localStorage`，確保重整後持久保存。
- **檢核重點**：
  - 新增卡片即時出現在第一筆，所有互動功能（按讚、雙擊照片、留言、收藏）即時可用。

## 驗收清單 (Checklist)

- [ ] 進入網頁時，過往日記卡片能正確自 `localStorage` 讀取並依時間倒序渲染。
- [ ] 介面色彩精準對應 PANTONE 莫蘭迪 8 大柔和色系（以 Cloud Dancer 與 Nimbus Cloud 為底色基調）。
- [ ] 點擊「快速記錄」開啟新增對話框，提供主題三選一（專業知識、心得雜記、資訊分享）。
- [ ] 支援「簡要輸入」模式（如輸入一句話或 Google Maps 網址），並具備範例按鈕可一鍵填入。
- [ ] 點擊生成後，系統能依 Rules 寫作風格（沉穩、低調、務實、微幽默、非說教）擴寫為完整小短文。
- [ ] 若輸入包含 Google Maps 連結，能調用 `google-maps-fetch` 技能，自動補充捷運交通、店家名稱與客觀避坑提醒。
- [ ] **生成的小短文能即時呈現在彈出視窗的編輯框中，供使用者親自確認與手動修改**。
- [ ] 配圖功能支援「自行上傳照片」與「連接 AI 依文章語意動態辨識生成 1:1 配圖」，絕無死板固定照片限制。
- [ ] **提供 AI「推薦 Hashtag」晶片列表，使用者可點擊快速選取/取消標籤**。
- [ ] **完成所有確認後「最後才發佈」**，卡片嚴格落實 Instagram 經典排版規格。
- [ ] 全站文字字型預設為微軟正黑體，無破版、無浮誇宣傳詞。
