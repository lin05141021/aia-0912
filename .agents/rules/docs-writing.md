# 內容創作、色彩體系與 IG 發文格式規範 (Content, Color & Instagram Card Rules)

本規範適用於專案內所有文章生成、生圖風格、介面視覺色彩以及社群卡片（Card）的版面架構設計。

---

## 1. 通用底層準則 (適用所有主題)

- **寫作語調**：
  - 定調為「**沉穩、低調、務實**」，專注陳述客觀事實、真實經歷與實作邏輯。
  - 避免無意義的空話與灌水，用精準具體的文字傳遞價值。
- **嚴禁浮誇形容**：
  - 嚴格禁止使用「地表最強」、「革命性突破」、「必吃神店」、「史詩級體驗」等過譽宣傳詞。
  - 真正好用、好看、好吃的東西默默運作並呈現即可，不需要自我吹捧。
- **字型規範**：
  - 未特別指定時，全域優先使用「**微軟正黑體 (Microsoft JhengHei)**」。
  - 網頁 CSS 宣告基準：
    ```css
    font-family: "Microsoft JhengHei", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
    ```
- **排版與標點細節**：
  - 中英文與數字之間保留一個半形空格（例如：`讀了 Clean Code`、`推薦 3 間店`）。
  - 中文段落使用全形標點符號（`，`、`。`、`！`、`？`、`：`）。
  - 專有名詞嚴格遵循官方大小寫（如 `GitHub`、`JavaScript`、`CSS`、`Git`、`Instagram`）。

## 3. 三大主題寫作與生圖風格定義

### 主題 A：心得雜記（生活體悟、學習反思）

- **主色系**：`PANTONE 13-3802 Orchid Tint` (淡蘭紫霧) 搭配 `PANTONE 11-1400 Raindrops on Roses` (柔粉)。
- **寫作風格**：
  - **克制幽默**：容許偶爾出現乾爽、會心一笑的微幽默，但點到為止，不過度喧鬧。
  - **自嘲元素**：加入適度且真實的自我解嘲（例如：debug 兩小時最後發現是少打一個括號、以為自己寫出極致邏輯結果隔天自己看不懂）。
  - **誠懇共鳴**：以平和心態記錄過程，不說教，像是在跟老朋友分享近況。
- **生圖風格**：
  - **視覺意境**：生活紀實感、安靜舒適的日常氛圍（Documentary Life Snapshot）。
  - **光影色調**：自然柔和光線、低飽和度暖灰調、真實生活細節（如窗邊的光影、散落的草稿紙、一杯溫熱的咖啡）。
  - **避免元素**：過度修飾的無瑕擺拍、過度飽和的人工濾鏡、花俏的 3D 卡通效果。

---

### 主題 B：專業知識分享（閱讀心得、文章金句、專業文章連結）

- **主色系**：`PANTONE 13-4306 Ice Melt` (融冰淡水藍) 搭配 `PANTONE 13-6006 Almost Aqua` (薄霧水綠)。
- **寫作風格**：
  - **嚴格檢核資訊正確性**：技術名詞、引述來源、原作者出處與原意必須查證確實，不傳遞未經驗證的謠言或錯誤代碼。
  - **實踐者分享視角**：避免居高臨下的「專家教學」口吻，切換為「**我自己用過了，覺得很順手**」或「**最近讀到這篇/聽說這個概念，感覺很厲害，整理重點跟大家分享**」的同儕視角。
  - **結構精練**：包含核心觀點、為什麼有感觸、實務應用建議，並附上精準文章連結。
- **生圖風格**：
  - **視覺意境**：俐落專業、具秩序感與專注氛圍的現代科技/工作空間（Clean Desk Setup）。
  - **元素組成**：深色/冷灰基調、簡約筆記本、現代筆電螢幕微光、極簡抽象架構示意或整齊的書桌桌面。
  - **避免元素**：浮誇廉價的藍紫霓虹賽博朋克光效、過度具象的機械假人、誇張的爆發特效。

---

### 主題 C：資訊分享（景點推薦）

- **主色系**：`PANTONE 12-1107 Peach Dust` (蜜桃粉杏) 搭配 `PANTONE 11-0515 Lemon Icing` (檸檬淡黃)。
- **寫作風格**：
  - **輕鬆隨興、風趣隨意**：語氣親切自然，多加一些活潑的生活化語助詞（「啦」、「吧」、「喔」），善用接地氣的標點與適度搭配 emoji（例如：🚶‍♂️、🍜、☕、⚠️、🚇）。
  - **非網美風、絕不業配**：單純務實分享個人的真實體驗，講優點也誠實揭露缺點（例如：「風景確實值得一看，但現場遮蔽物少、中午真的會曬暈，務必帶陽傘」、「牛肉湯肉質鮮甜，但老闆脾氣很個性，建議避開人潮顛峰」）。
  - **務實情報**：包含具體避坑指南、適合拜訪的時段與交通便利性。
- **生圖風格**：
  - **視覺意境**：自然旅途隨拍視角（Street & Travel Documentary Photography）。
  - **光影色調**：晴朗真實自然光、街景環境光、真實食物紋理與生活氛圍。
  - **避免元素**：刺眼的網美磨皮感、過度夢幻的粉紅/橘黃超飽和濾鏡、不合常理的擺設。

## 4. Instagram (IG) 發文格式規範與卡片設計

所有主題的日記卡片均應嚴格參考 Instagram 經典 Feed Post 的版面排版結構：

```text
┌────────────────────────────────────────────────────────┐
│  [頭像]  username                    [··· 更多操作]    │
│          台北 • 永康街角落咖啡 • 💡 專業知識           │
├────────────────────────────────────────────────────────┤
│                                                        │
│                                                        │
│               主照片 (1:1 正方形 或 4:5 縱向)          │
│               [雙擊爆發大愛心互動]                     │
│                                                        │
│                                                        │
├────────────────────────────────────────────────────────┤
│  [❤️ 點讚]   [💬 留言]   [✈️ 分享]             [🔖 收藏]│
│                                                        │
│  142 個讚                                              │
│  username  今天在轉角咖啡讀了 Clean Code，體會到極簡的踏  │
│            實感... 更多                                │
│                                                        │

│                                                        │

├────────────────────────────────────────────────────────┤
│  😊  新增留言...                               [發佈]  │
└────────────────────────────────────────────────────────┘
```

### 卡片八大結構標準

1. **Card Header (發文者標頭區)**：
   - **圓形頭像 (Avatar)**：直徑 38~42px，外圍保留 1.5px 莫蘭迪柔和邊框。
   - **帳號資訊**：
     - 第一行：**使用者名稱**（加粗 600 weight）。
     - 第二行：**地點標記** + **主題分類 Badge**（套用對應的 PANTONE 莫蘭迪色標籤）。
   - **更多按鈕 (`···`)**：右上方三點圖示，提供複製連結、刪除或收藏動作。

2. **Card Media (發文主視覺照片)**：
   - **比例規範**：嚴格維持 Instagram 黃金視覺比例：`1:1` 正方形（手機端）或 `4:5` 垂直直向（桌面端），嚴禁隨機長寬比破壞整齊感。
   - **互動反饋**：支援圖片上「**雙擊（Double-tap）跳出紅色大愛心縮放動畫**」。

3. **Action Bar (互動工具列)**：
   - 左側三劍客：
     - ❤️ **愛心 (Like)**：點擊跳動並轉為亮紅（`#ef4444`）填滿狀態。
     - 💬 **留言 (Comment)**：點擊自動聚焦到底部留言框。
     - ✈️ **分享 / 紙飛機 (Share)**：點擊複製卡片連結並跳出 Toast 提示。
   - 右側獨佔：
     - 🔖 **書籤收藏 (Save)**：點擊切換為黑色/深色填滿狀態。

4. **Metrics (讚數列)**：
   - 格式為：`XX 個讚` 或 `142 次贊`（字體加粗 `font-weight: 600`）。

5. **Caption & Text (正文首行排版)**：
   - 遵循 Instagram 經典文案格式：**`username`** 接半形空格後直接接內文第一句。
   - 內文若超過三行，提供「... 更多」展開全文按鈕。

6. **Tags (主題標籤區)**：
   - 標籤前綴統一為 `#`，以柔和的品牌藍或深灰顯示（如 `#專業知識 #生活雜記`）。

7. **Comments & Timestamp (留言區與時間戳記)**：
   - 顯示「查看全部 X 則留言」灰色文字連結。
   - 預設列出 1~2 則最新精選留言（格式為：`username` 內文）。
   - 時間戳記（如 `2 小時前` 或 `9 月 12 日`）以低調灰階、小字號（0.75rem）呈現於下方。

8. **Add Comment Bar (底部即時留言框)**：
   - 包含表情符號按鈕（😊 / ❤️）、無邊框純文字輸入框（`新增留言...`），以及在有文字輸入時高亮啟用的「**發佈**」字樣按鈕。
